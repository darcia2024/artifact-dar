# Kesiapan Sistem — Underrated Barbershop

Halaman status kesiapan sistem menjelang pembukaan: apa yang sudah berjalan,
urutan langkah di hari pertama, dan data yang masih perlu diisi klien.

Buka `kesiapan.html` langsung di browser — halaman ini berdiri sendiri, tanpa
build dan tanpa dependensi. Satu-satunya sumber luar adalah Google Fonts.

## Yang sengaja tidak ada di sini

Email, kata sandi, dan PIN **tidak** dimuat di repositori ini, dan tidak boleh
ditambahkan. Repositori ini publik; kredensial yang pernah ter-commit akan
terbaca siapa pun yang meng-clone dan tetap ada di riwayat Git meski berkasnya
dihapus kemudian.

Kredensial dikirim langsung ke masing-masing orang, dan tiap orang hanya
menerima miliknya sendiri.

## Sistem yang dijelaskan halaman ini

Sistem membership & loyalty barbershop: POS kasir, dashboard owner, halaman
capster, kartu member, absensi, dan setoran kas harian. Kode aplikasinya ada di
repositori terpisah.
