Prinsip utama

AI hanya membantu memahami pertanyaan. Angkanya selalu dari data resmi.

Aplikasi tidak mengarang angka. Setiap jawaban bisa ditelusuri ke sumber datanya.

Keamanan data

Data tetap di Indonesia. Data pribadi tidak dibawa keluar.

Hak akses sesuai jabatan

Sekda, Bupati, dan kepala dinas. Kepala dinas hanya melihat data dinasnya.

Semua akses tercatat

Siapa membuka data apa dan kapan, termasuk setiap pertanyaan, bisa diperiksa.

Data terkunci

Data disimpan dan dikirim dalam keadaan terenkripsi.

Diuji pihak luar

Keamanannya diuji pihak independen sebelum aplikasi dipakai.

Server di Indonesia

Pusat data pemda, Pusat Data Nasional, atau penyedia dalam negeri. Dipilih bersama Diskominfo.

AI tidak melihat data pribadi

AI hanya menerima angka ringkasan. Data pegawai dan penerima bantuan tetap di server pemda.

Sesuai UU Pelindungan Data Pribadi

Data yang terpaksa dikirim dikurangi seperlunya atau disamarkan.

Perpres tentang AI belum terbit. Aplikasi dibuat supaya mudah diubah saat aturan itu keluar.

Tidak dikerjakan developer: mengubah aplikasi dinas yang sudah ada, mengadakan server dan Claude API (oleh Pemkab), uji keamanan independen (BSSN), dan menjamin kebenaran isi data dinas.

Boleh diakses

  • Repositori kode milik Pemkab
  • Server pengembangan dan uji coba, berisi data contoh atau yang disamarkan
  • Struktur data sistem dinas, tanpa isi data pribadi
  • Antarmuka aplikasi dinas, hanya baca, atas izin pemiliknya
  • Kunci Claude API khusus uji coba, dengan batas pemakaian
  • Log teknis tanpa data pribadi
  • Cloudflare dan pemantauan milik Pemkab, peran terbatas

Dengan izin Diskominfo

  • Masuk server produksi lewat VPN untuk pemasangan atau perbaikan, tanpa mengunduh data
  • Melihat angka ringkasan produksi bersama penanggung jawab data
  • Memasang versi baru setelah diuji dan disetujui

Sementara, dan setiap akses tercatat.

Tidak boleh diakses

  • Data per orang: data pegawai, penerima bantuan
  • Menyimpan data asli di komputer pribadi atau di luar Indonesia
  • Kata sandi dan akun pengguna Pemkab
  • Akun admin utama server dan kunci enkripsi
  • Kunci Claude API produksi dan akun pembayaran
  • Mengubah atau menghapus catatan akses
  • Menulis data di sistem dinas
  • Mengirim data mentah ke AI atau pihak lain

Pilihan model AI

Saran dari AI terbaik, data tetap di Indonesia

AI yang paling pintar saat ini hanya bisa dipakai lewat layanan penyedianya, dan servernya umumnya di luar negeri. Karena itu kami mengusulkan cara gabungan.

Pilihan A

Model terbaik lewat layanan penyedia

Kualitas saran paling tinggi. Tetapi data ringkasan dikirim ke luar negeri.

Pilihan B

Model terbuka di server sendiri

Tidak ada data yang keluar. Tetapi kualitasnya lebih rendah dan butuh server GPU yang mahal.

Pilihan C · usulan kami

Gabungan

Semua data dan perhitungan tetap di server Indonesia. Model terbaik hanya menerima pertanyaan dan angka ringkasan, lalu menyusun saran dengan bahasa yang mudah dipahami. Data per orang tidak pernah dikirim.

Aplikasi dibuat agar modelnya bisa diganti. Jika nanti aturan mewajibkan model dalam negeri, Pemkab cukup beralih tanpa membangun ulang. Penggunaan model dari luar negeri tetap menunggu persetujuan Diskominfo di Fase 0, sesuai UU Pelindungan Data Pribadi.

Server atas nama Pemkab, keamanan berlapis

Server sebaiknya dikontrak langsung oleh Pemkab, supaya data dan asetnya milik daerah. Kami menyusun spesifikasinya, memasang aplikasi, dan merawatnya.

Pilihan 1

Pusat data Diskominfo atau PDN

Jika kapasitas dan petugas jaganya memadai.

Pilihan 2

Cloud privat di pusat data Indonesia

Dibeli Pemkab lewat e-katalog, di pusat data bersertifikat ISO 27001.

Pilihan 3 · sementara

Server sewa selama pembangunan

Ukurannya disesuaikan dengan jumlah pengguna yang puluhan orang, supaya tidak boros anggaran. Kapasitas bisa dinaikkan kapan saja tanpa membangun ulang.

Pintu masuk

Firewall jaringan, firewall aplikasi web, dan perlindungan dari serangan banjir lalu lintas.

Akses

Semua pengguna masuk dengan verifikasi dua langkah. Akses admin ke server hanya lewat VPN.

Data

Terenkripsi saat disimpan dan dikirim. Kunci enkripsi disimpan terpisah.

Pengawasan

Pemantauan serangan 24 jam, catatan akses yang tidak bisa diubah, dan pemindaian celah setiap bulan.

Pemulihan

Cadangan harian dengan aturan 3-2-1 dan uji pemulihan sebelum serah terima.

Pengujian

Uji penetrasi oleh BSSN (ITSA) atau penguji independen yang diajukan Pemkab, lalu uji ulang setelah perbaikan.

Tata kelola dan akuntabilitas

Setiap rupiah bisa dipertanggungjawabkan

Kami ingin proyek ini aman bagi Pemkab dan bagi kami, termasuk saat diperiksa auditor.

Harga dengan dasar yang jelas

Rincian biaya per tenaga ahli mengacu pedoman tarif resmi, ditambah perbandingan penawaran untuk server dan layanan.

Bayar sesuai hasil

Pembayaran per fase setelah berita acara serah terima, dengan kriteria penerimaan yang tertulis.

Server, AI, dan uji keamanan dibayar langsung

Pemkab membayar langsung ke penyedia sesuai pemakaian nyata, tanpa melalui kami.

Bukti kerja setiap bulan

Laporan kemajuan, catatan jam kerja tenaga ahli, dan riwayat pekerjaan diserahkan dan diparaf Pemkab.

Perubahan selalu tertulis

Setiap perubahan lingkup dibuat lewat addendum resmi, bukan kesepakatan lisan.

Komitmen integritas

Kontrak dan pembayaran sesuai bentuk penyedia yang disepakati, ke rekening atas nama penyedia, dan taat pajak. Tidak ada hadiah atau fee untuk pejabat. Pekerjaan berbayar baru dimulai setelah kontrak terbit; presentasi ini tidak dipungut biaya. Pelaksana dan perwakilan lapangan bukan ASN dan tidak terlibat dalam pengadaan.

Usulan ketentuan dalam kontrak

Kami usulkan dicantumkan dalam syarat khusus kontrak

KetentuanIsinya
Hasil kerja tiap faseDitulis jelas, termasuk jasa tenaga ahli: rancangan, kode program, pengujian, dan pelatihan. Semuanya dinilai sebagai hasil kerja yang punya nilai.
Penetapan HPSHarga Perkiraan Sendiri ditetapkan oleh PPK Pemkab. Dar Dev hanya menyampaikan penawaran resmi beserta rincian biayanya.

Server dan layanan AIDikontrak dan dibayar langsung oleh Pemkab kepada penyedia, sesuai pemakaian nyata.
Tanggung jawab atas dataKebenaran isi data tetap tanggung jawab dinas pemilik data. Tanggung jawab kami adalah mengolah dan menampilkannya sesuai cara hitung yang disepakati.
Penggunaan alat bantu AI dalam pengembanganDeveloper boleh memakai alat bantu AI, misalnya Claude Max dan Claude Code, untuk merancang, menulis kode, menguji, dan menyusun dokumen. Syaratnya: tidak ada data asli atau data pribadi yang dimasukkan, semua hasil diperiksa dan diuji serta menjadi tanggung jawab penuh developer, dan alat yang dipakai disebutkan di laporan bulanan. Pemakaian AI tidak mengurangi nilai jasa, karena nilai jasa dihitung dari hasil kerja yang diterima dan hari kerja yang disepakati.
Hak ciptaKode program, dokumen, dan panduan diserahkan kepada Pemkab saat serah terima, termasuk bagian yang dibuat dengan bantuan AI.
PerubahanPerubahan lingkup, jadwal, atau harga hanya lewat addendum tertulis.

Ketentuan ini usulan kami dan akan disesuaikan dengan format kontrak standar yang disusun PPK.

Kita mulai dari Fase 0, satu bulan.
